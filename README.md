## 🔨 Featured Projects

**[Mood Reader](https://github.com/MayhemGOAT/mood_reader)** — multimodal music mood classifier
Fuses lyrics NLP (DistilRoBERTa, VADER) with librosa audio features to predict valence, energy, and discrete vibe labels — no Spotify API required at inference. Gradient-boosting pipeline with Genius/Spotify/Last.fm dataset tooling and a full evaluation suite. *Python · PyTorch · scikit-learn · librosa*

**[PulseX](https://github.com/MayhemGOAT/PulseX)** — AI trading assistant
Evolved from my [quant-backtester](https://github.com/MayhemGOAT/quant-backtester) experiment on AAPL return forecasting. Fuses LLM-sourced market sentiment from X with technical signals to produce per-ticker trade ideas (UP/DOWN/HOLD/TRIM/SELL), with beginner-friendly prompts and a strategy backtester. *Python · scikit-learn · yfinance · pytest*

**[COVID-19 Strain Classifier](https://github.com/MayhemGOAT/COVID-19_Strain_Analysis_Prediction)** — applied ML research
Interactive Streamlit app that classifies COVID-19 strains from Raman spectra — the applied side of my ACS Omega work at IIT Delhi. *Python · scikit-learn · Streamlit*

**[AI Assessment Platform](https://github.com/MayhemGOAT/ai-assessment)** — full-stack app
AI-powered assessment generation with a FastAPI backend, Next.js frontend, and PostgreSQL, containerized with Docker. *FastAPI · Next.js · PostgreSQL · Docker*
