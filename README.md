## 🔨 Featured Projects

**[Mood Reader](https://github.com/MayhemGOAT/mood_reader)** — Multimodal Music Mood Classifier  
Fuses lyrics NLP (DistilRoBERTa, VADER) with librosa audio features to predict valence, energy, and discrete vibe labels. Gradient-boosting pipeline with high generalization on out-of-distribution music. No Spotify API required at inference.  
*Python · PyTorch · scikit-learn · librosa*

**[PulseX](https://github.com/MayhemGOAT/PulseX)** — AI-Powered Trading Assistant  
Evolved from my [quant-backtester](https://github.com/MayhemGOAT/quant-backtester) experiment on AAPL return forecasting. Fuses LLM-sourced market sentiment from X (Twitter) with technical indicators to generate buy/sell signals. Combines NLP sentiment analysis with quantitative signals for data-driven trading decisions.  
*Python · LLMs · API Integration · Time-Series Analysis*

**[COVID-19 Strain Classifier](https://github.com/MayhemGOAT/COVID-19_Strain_Analysis_Prediction)** — Applied ML Research  
Interactive Streamlit app that classifies COVID-19 strains from Raman spectra. Translates lab research (ACS Omega publication) into an accessible tool for real-world deployment.  
*Python · scikit-learn · Streamlit · Signal Processing*

**[AI Assessment Platform](https://github.com/MayhemGOAT/ai-assessment)** — Full-Stack Application  
Production-ready AI platform for adaptive assessment generation. FastAPI backend handles LLM orchestration, Next.js frontend provides smooth UX, PostgreSQL stores assessments securely. Fully containerized with Docker for seamless deployment.  
*FastAPI · Next.js · PostgreSQL · Docker · AWS*
